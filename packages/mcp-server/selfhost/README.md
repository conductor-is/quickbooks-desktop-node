# Self-hosting runbook home

This directory holds the parity baselines, verification script, and deploy log for this package's HTTP server.
Conductor runs the image as the private Render service `conductor-code-runner`, the backend of the `execute` tool on `https://mcp.conductor.is/`, defined in the conductor repo's `render.yaml`: blueprint-managed, and it auto-deploys every commit on this repo's main after CI passes. `DEPLOYS.md` is the deploy history of `conductor-mcp`, the public service that ran it until 2026-11-23; `verify.sh` is the parity gate to re-run after any runtime change (regen, MCP SDK bump, deno base image), diffing against the snapshot files beside it.
The runtime stage of `../Dockerfile` is `denoland/deno:alpine-2.9.8` (Alpine 3.24) with Alpine's `nodejs` package installed at a minimum of `24.22.1-r0` (the `NODE_MIN_VERSION` build argument): `apk` refuses the build when the release offers nothing at or above the minimum, and a `node` check after the install fails it when the installed version is lower. Deno 2.9.8 and Node.js 24.22.1 are the first releases that distrust the compromised eMudhra CA certificates and carry the 2026-10-21 Node.js security fixes. To bump the base image: read the new image's `/etc/alpine-release`, set `NODE_MIN_VERSION` to the patched Node.js version that release's `main` repository carries, move the pinned Deno job in `.github/workflows/ci.yml` to the same Deno version, then re-run `verify.sh` with `RUN_SLOW=1` against the deployed service (the gate the conductor repo's `stainless/README.md` requires for any base-image change) and append the deploy to `DEPLOYS.md`.
The OAuth resource the server advertises (its RFC 9728 documents and 401 challenges) is always `https://mcp.conductor.is/`, the one origin Conductor's dashboard accepts for sign-in; a server run at another origin takes its key in the `Authorization` header.

The package's stdio transport is a bridge to the hosted server at `https://mcp.conductor.is/`; `CONDUCTOR_MCP_URL` overrides its upstream (default `https://mcp.conductor.is/`), which is how tests/execute-smoke.mjs drives the bridge against a local `--transport=http` instance.
